# Capability Contract Catalog

This catalog inventories the stable user- or Host-observable promises made by the current Pi Stuff Suite. The owning
Capability Module README remains the local contract authority. One row represents one durable Contract ID and groups
its normal, failure, recovery, persistence, and boundary scenarios; private functions and individual test cases are
not separate contracts.

The status classes are `pending`, `blocked`, `pass`, and `fail`. `pending` means the contract has not been
accepted against the current certified Host profile. A Conditional Capability Contract becomes `blocked`, rather
than passed or skipped, when its configured success scenario cannot run because an optional executable, credential,
Provider, or Service is unavailable. `pass`, `fail`, and `blocked` require a linked dated acceptance report.

The Evidence column declares the smallest current evidence set expected for acceptance; it does not itself claim that
the evidence has been rerun. The retained [2026-08-30 acceptance snapshot](reports/ps-ps3-capability-contract-and-terminal-bench-observation-2026-08-30.md)
is historical evidence for Pi 0.84.3 and does not certify these current `pending` entries.
